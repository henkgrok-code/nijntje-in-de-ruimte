# Nijntje in de Ruimte

Een schattig browser-arcadespel. Speel het online (HTTPS), zodat kantelbesturing op de telefoon werkt.

**Spelen:** https://henkgrok-code.github.io/nijntje-in-de-ruimte/

Besturing: pijltjes of A/D, spatie om te schieten, P voor pauze. Op de telefoon: knoppen, slepen, of kantelen.
