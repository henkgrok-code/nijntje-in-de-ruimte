# Nijntje in de Ruimte

Een schattig browser-arcadespel. Speel het via HTTPS, zodat kantelbesturing op de telefoon werkt.

Je kunt Nijntje ook omhoog en omlaag sturen (pijltjes / WASD, kruis op het scherm, slepen, of kantelen).

**Spelen (aanbevolen, vastgelegde versie):**  
https://cdn.githubraw.com/henkgrok-code/nijntje-in-de-ruimte/0b5c135f3dffc7cdb674181b0e567939238d76f5/index.html

**Spelen (volgt `main`, cache kan een paar minuten achterlopen):**  
https://githubraw.com/henkgrok-code/nijntje-in-de-ruimte/main/index.html

Besturing: pijltjes of WASD om te bewegen, spatie om te schieten, P voor pauze. Op de telefoon: kruis, slepen, of kantelen.

GitHub Pages staat klaar (workflow in `.github/workflows/pages.yml`) maar moet eenmalig worden aangezet in de repository-instellingen (Settings → Pages → Source: GitHub Actions). Daarna is het spel ook te bereiken op https://henkgrok-code.github.io/nijntje-in-de-ruimte/
