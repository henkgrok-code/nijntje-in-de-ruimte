# Nijntje in de Ruimte

Een schattig browser-arcadespel. Speel het via HTTPS, zodat kantelbesturing op de telefoon werkt.

**Spelen:** https://raw.githack.com/henkgrok-code/nijntje-in-de-ruimte/main/index.html

Besturing: pijltjes of A/D, spatie om te schieten, P voor pauze. Op de telefoon: knoppen, slepen, of kantelen.

GitHub Pages staat klaar (workflow in `.github/workflows/pages.yml`) maar moet eenmalig worden aangezet in de repository-instellingen (Settings → Pages → Source: GitHub Actions). Daarna is het spel ook te bereiken op https://henkgrok-code.github.io/nijntje-in-de-ruimte/
